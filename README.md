# 宜昌旅行记 · 共建版 0.1

一个纯前端、零后端、零存储的宜昌在地指南。双击 `宜昌旅行记.html` 就能看，数据全部写死在 `data.js` 里，不联网、不写 localStorage。

- 首页：宜昌 13 个县市区矢量地图，城区单独放大成 5 个区
- 区县页：区县实景照片 + 区界轮廓 + 美食 / 玩乐 / 住宿 / 景点 / 机位
- 栏目页：区县推荐地图 + 地点列表
- 地点页：平台评分、推荐人数、综合评分；机位只显示推荐人数
- 背景：13 个区县各一张实景图，已配好；换成自己的照片只需同名覆盖

## 文件

```
宜昌旅行记/
├─ index.html          界面、动效、路由、评分计算

├─ 宜昌旅行记.html      单文件版（build.py 生成，可直接发给别人）
└─ README.md
```

## 改数据

打开 `data.js`，每个地点是一行：

```js
P(名称, 类型标签, 大众点评分, 携程分, 推荐人数, 一句话推荐, 位置)
```

- 住宿只填携程分：`P('宜昌温德姆至尊酒店', '酒店', null, 4.7, 210, '...', '沿江大道158号')`
- 景点两个都填：`P('三峡大坝', '工程', 4.7, 4.6, 880, '...', '三斗坪')`
- 机位两个都留 null：`P('宜昌万达富力皇冠假日酒店对面', '机位', null, null, 240, '...', '沿江大道')`
- 某栏目为空就写 `[]`，界面会显示「这一栏还空着」

名称按百度地图上的叫法写，同名分店加上括号，例如「王氏凉虾（解放路店）」。正式版把 `meta.demo` 改成 `false`，所有「示例」角标会消失。

## 共建格式

评论区只收三段：**区域 · 类型 · 名称**

```
西陵区 · 美食 · 王氏凉虾
```

不需要写理由，不需要写地址；名称尽量和百度地图一致，方便直接落到地图上。

## 评分（内部规则，界面不展示）

```
平台分 P：住宿 = 携程；景点 = 大众点评与携程均值；其他 = 大众点评
推荐分 R：0–9 → 1 / 10–99 → 2 / 100–299 → 3 / 300–499 → 4 / 500+ → 5
综合评分 = (P × 4 + R) ÷ 5      // 保留一位小数
```

机位不参与评分，只显示推荐人数。改规则只需要改 `index.html` 里的 `recScore()` 和 `scoreOf()`。

## 更新数据

1. 导出帖子评论区（小红书后台或手动复制）
2. 按「区域 · 类型 · 名称」归并，去重，统计提及人数
3. 更新 `data.js` 里对应地点的 `recs`，平台分顺手核一遍
4. 改 `meta.updated`
5. `python3 build.py` 重新生成单文件版

没有自动抓取，也不做定时任务；更新一次就改一次 `data.js`。

## 发布

整个目录丢到任意静态托管（Vercel / Netlify / GitHub Pages / 对象存储）即可，不需要服务端。
`index.html` 也可以直接本地双击打开。
